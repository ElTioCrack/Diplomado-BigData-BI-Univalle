# Proyecto — Visualización y Recuperación de Datos

Descripción
-
Conjunto de entregas del curso "Diplomado en Big Data, Analytics y Business Intelligence" (módulo: Visualización de Datos y Data Recovery).

Estructura del repositorio
-
- `requirements.txt` — dependencias Python.
- `A1/` — Notebook de la primera entrega.
- `A2/` — Datos crudos y notebooks de ETL / limpieza.
- `A3/` — Notebook de modelos descriptivos y datos de ejemplo.

Uso rápido
-
1. Crear y activar un entorno virtual (recomendado):

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

2. Instalar dependencias:

```bash
pip install -r requirements.txt
```

3. Abrir los notebooks con Jupyter/VS Code:

```bash
jupyter lab
```

Notas
-
- Los notebooks principales están dentro de las carpetas `A1/`, `A2/` y `A3/`.
- Los conjuntos de datos de ejemplo están dentro de `A2/dataset/` y `A3/dataset/`.
- Si maneja datos grandes, considere no subirlos al repositorio y usar un almacenamiento externo.
